# Проверка поддержки Codex

Реализация проверена на Windows с Codex CLI 0.166.0 и авторизацией ChatGPT. Рабочая база пользователя не использовалась: проверки создают отдельные временные копии, базы и порты. Реальный Claude не запускался по прямому указанию владельца.

## Проверенные требования

| Требование | Доказательство |
| --- | --- |
| Два стартовых файла | `start_claude.cmd` и `start_codex.cmd`; старый `start.cmd` удалён. Реальный запуск Codex через CMD; команда Claude проверена без выполнения CLI. |
| Сохранение исполнителя | Реальный перезапуск сервера меняет boot_id, сохраняет agent=codex и id сессии. `spawn_successor` передаёт `--agent` явно; обновление использует тот же путь перезапуска. |
| Запуск по подписке | Реальные account/read, model/list и модельные запросы через app-server с входом ChatGPT. API-ключи не используются; OpenAI закреплён как провайдер. |
| Простой запуск | Реальный `start_codex.cmd --no-browser` на чистой тестовой базе; никаких дополнительных библиотек. Проверены сообщения об отсутствующем CLI и устаревшей версии. |
| Очередь и параллельность | Автоматический тест запускает задачи двух проектов параллельно и удерживает вторую задачу первого проекта в очереди. Проверено плавное выключение. |
| Вопрос и продолжение | Реальная задача создаёт файл, вызывает MCP ask_user, получает ответ и продолжает тот же session_id. |
| Отчёт и повторная работа | Реальные finish_task, файл отчёта, HTTP-страница отчёта и повторный запуск завершённой задачи в прежней сессии. Автоматически проверено сохранение предыдущего отчёта. |
| Разрешить и запретить | Независимый проверяющий выполнил реальные проверки read-only: одобрение создало файл; отказ не создал файл. Автоматические тесты проверяют мост approve/approve_status. |
| Остановка и продолжение | Независимый реальный тест остановил активный CodexRun, дождался finished и статуса interrupted, затем продолжил ту же сессию до done. |
| Восстановление после сбоя | Автоматические тесты running → resume и waiting с осиротевшим permission → resume. Настоящий открытый вопрос сохраняет waiting. |
| Лимит подписки | Управляемые события usageLimitExceeded: сохранение resume, пауза до известного resetsAt либо помеченная оценочная повторная попытка. Настоящая квота не исчерпывалась. |
| Чаты, файлы и картинки | Реальный чат прочитал текстовый маркер из вложения и распознал красный цвет PNG. Отдельные тесты проверяют хранение/выдачу вложений, разделение сессий и управление чатами. |
| Названия и импорт | Реальные автоматическое название чата и структурированный импорт двух задач. Ручное название защищено автоматическим тестом. |
| MCP и связи задач | Реальные MCP-вызовы из Codex, автоматические проверки схем/ролей, создания связанной задачи и передачи связей в промпт. |
| Режимы Git | Контракт промптов off/commit/commit_push проверен автоматически. Существующие инструкции сохранены. Реальные коммиты и push в рамках проверки не выполнялись. |
| Существующая база | Тест начинает со схемы без новых колонок: миграция сохраняет старые Claude session_id, модель и стоимость, добавляет пустые поля Codex. Проверены раздельные чтение/запись сессий и настроек и перенос контекста после неудачного запуска. |
| Защита базы | Два процесса не могут получить файловую блокировку одной папки data; блокировка берётся до импорта db и recover. Проверка выполняется без запуска Claude. |
| Очистка процессов | В реальных сквозных, permission и kill/resume проверках тестовых процессов после завершения не осталось. Служебные генерации учитываются при штатном перезапуске. |
| Интерфейс и effort | Реальный Edge/CDP: 1280×900 и 390×844, без ошибок JS и горизонтального переполнения. У моделей с high/low различаются списки effort. Несовместимый effort дополнительно проверяется на сервере. |
| Документация | Добавлен AGENTS.md; обновлены CLAUDE.md, README.md и CONTRIBUTING.md. |

## Команды и результаты

```
python -m unittest discover -s tests -v
# 18 tests, OK; без обращений к моделям

node --check web/app.js
# OK

python tests/ui_check.py
# desktop/mobile: errors=[], overflow=false, loaded=true

python tests/live_codex.py
# 8 сквозных этапов, success=true

git diff --check
# OK
```

Синтаксис всех Python-модулей server/ и tests/ проверен через `compile()` без импорта рабочей базы. Node и Edge нужны только для необязательных проверок интерфейса; для работы трекера они не добавлены в зависимости.

Сквозной тест выполнен основным агентом и независимо повторён проверяющим. Временные каталоги каждого запуска содержат `evidence.json`, тестовую базу, отчёты и JSONL. Независимый проверяющий дополнительно воспроизвёл реальные разрешение/отказ и kill/resume, проверил требования цели и повторил автоматические проверки. Найденные им ошибки переноса контекста, фильтрации событий и восстановления ожидания разрешения исправлены и защищены регрессионными тестами.

## Границы проверки

- Claude CLI, его авторизация и модельные запросы намеренно не запускались. Совместимость проверялась анализом кода, сборкой команды и заглушками событий.
- Лимиты, аварийные состояния и параллельность проверялись управляемыми сценариями без исчерпания подписки и без задач пользователя.
- Реальный pull обновления не выполнялся: репозиторий не публиковался. Сохранение исполнителя проверено на общей функции перезапуска, которую вызывает обновление.
- Тесты подтверждают перечисленные сценарии на проверенной версии CLI. Минимальная версия указана явно; более старый CLI получает инструкцию обновления.
